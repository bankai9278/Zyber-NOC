// how it works

Four steps from IP address to insight.

  1. 01{{ icon("add") }}

    Save a device

    Add a name and an IP. Broadcast, multicast, unspecified and reserved addresses are refused before anything is stored.

  2. 02{{ icon("ping") }}

    Check it

    Windows ping -n 5 measures min, median, max, jitter and loss. TCP checks try one allowed port.

  3. 03{{ icon("store") }}

    Keep every result

    Each check is written to SQLite with parameterized SQL. A change in status is saved as its own event.

  4. 04{{ icon("see") }}

    See the story

    Uptime, the 90-day bar, latency bands, incidents, the topology tree and reports are all drawn from those rows.
