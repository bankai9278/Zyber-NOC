// how it helped me

From a design on paper to the tool that watches it.

Designing Skyline's network taught me how enterprise networks are structured: core, distribution and access layers, VLANs, firewalls and structured cabling. Zyber NOC is the next step. Instead of only designing a network on paper, I wanted to build the tool a NOC team would use to watch one.

The device types, parent devices, locations, VLANs and topology map in Zyber NOC all come from thinking in that same core -> distribution -> access hierarchy.
